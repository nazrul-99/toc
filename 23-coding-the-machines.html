Overview

Coding the machines of the course

Every machine in this course is just a small data structure plus a short loop. This page builds seven of them in plain Python, explains each line, and runs the code step by step next to the machine, so you can see exactly what every line does.

What we build

How to use each part

  1. Read the guide: each step says what to do and which lines do it (hover to highlight them).
  2. Look at the representation: hover a line of the dictionary to see the arrows it stores.
  3. Run the tracer: press Step to execute one line at a time; watch the highlighted line, the variables and the machine.
  4. Copy the complete program and run it with python file.py (Python 3, no libraries needed).
  5. Try the exercises: small changes that connect the code back to the problem sets.
