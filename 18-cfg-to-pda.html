From a context-free grammar to a PDA

Every context-free grammar can be turned into a PDA that accepts the same language. The PDA simulates leftmost derivations on its stack.

The standard construction (as covered in class)

PartChoice
Statesa single state q
Stack alphabetΓ = V ∪ T ∪ {Z₀}
Initial stackS Z₀ (S on top)
Expandδ(q, ε, A) = {(q, α) : A → α is a production}, for every variable A
Matchδ(q, a, a) = {(q, ε)}, for every terminal a
Finishδ(q, ε, Z₀) = {(q, ε)}, so the stack can become empty
Acceptanceby empty stack

Why it works

If the top of the stack is a variable, the PDA guesses a production and replaces it (one step of a leftmost derivation). If the top is a terminal, it must match the next input symbol. At every moment, the input read so far followed by the stack contents is a left-sentential form of the grammar. The stack empties exactly when the whole string has been derived.

How to write the answer

  1. List one expand transition for each production (group them by variable).
  2. List one match transition for each terminal.
  3. Add the finishing move for Z₀.
  4. For the sample string, write the leftmost derivation first; then each derivation step becomes one expand move, and each terminal becomes one match move.
