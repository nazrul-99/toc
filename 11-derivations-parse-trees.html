Derivations and parse trees

A derivation rewrites the start symbol step by step, replacing one variable by the right side of one of its productions, until only terminals remain.

Definitions

TermMeaning
Leftmost derivation ⇒lmAt every step the leftmost variable of the sentential form is replaced.
Rightmost derivation ⇒rmAt every step the rightmost variable is replaced.
Parse treeRoot = start symbol; each interior node is a variable A whose children, read left to right, form the right side of a production A → α; leaves are terminals or ε. Reading the leaves left to right gives the yield, the derived string.

Key fact

Every parse tree has exactly one leftmost derivation and exactly one rightmost derivation. Both use the same productions at the same tree nodes; they only visit the nodes in a different order (left first versus right first). So for a given parse tree the "leftmost tree" and the "rightmost tree" are the same tree.

They can only be different trees when the string has several parse trees, i.e. when the grammar is ambiguous for that string. On each page here, the number of parse trees of the string is computed.

How to write the answer

  1. Write the start symbol on the first line.
  2. For ⇒lm, find the leftmost variable in the current line, choose the production that can still produce the target string, and write the new line.
  3. For ⇒rm, do the same with the rightmost variable. Working from the right end of the string helps.
  4. Draw the tree: each step adds the children of the replaced variable.
  5. Compare the trees node by node.
