Minimization by the partition method

Two states are equivalent if, for every string w, reading w from either state ends in a final state for both or for neither. Equivalent states can be merged. The partition method finds all equivalent states by starting from a coarse partition and splitting blocks until nothing changes.

The procedure

  1. Remove unreachable states. Search from the start state; delete every state not reached (problem 6.9 shows why this step is needed).
  2. Round 0. Two blocks: final states and non-final states (ε tells them apart).
  3. Compute signatures. For each state, write the pair (block of δ(q, 0), block of δ(q, 1)) using the blocks of the previous round.
  4. Split. Inside each block, states with different signatures go to different new blocks. Write the reason: which symbol leads them to different blocks.
  5. Repeat until a round produces no split. The partition is then stable.
  6. Build the minimal DFA. One state per block; the start block contains the old start state; a block is final if its states are final; transitions are taken from any member.

Why it works

States in different blocks are always distinguishable: the splitting symbol, followed by the string that separated the target blocks, is a distinguishing string. When no more splits happen, the states left together cannot be distinguished by any string. Each problem page has a pair tester that finds the shortest distinguishing string for any two states.
