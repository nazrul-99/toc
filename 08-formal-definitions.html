Formal definitions and the extended transition function

DFA

A deterministic finite automaton is a 5-tuple M = (Q, Σ, δ, q₀, F)

ComponentMeaning
Qa finite set of states
Σa finite input alphabet
δ : Q × Σ → Qthe transition function: exactly one next state
q₀ ∈ Qthe start state
F ⊆ Qthe set of final (accepting) states

For an NFA the only change is δ : Q × Σ → 2^Q, a set of next states (possibly ∅).

The extended transition function δ̂

δ̂(q, w) is the state reached from q after reading the whole string w. It is defined by recursion on w:

δ̂(q, ε) = q     δ̂(q, xa) = δ( δ̂(q, x), a )

where a is the last symbol of the string. The language of M is L(M) = { w ∈ Σ* : δ̂(q₀, w) ∈ F }.

Expanding δ̂ peels symbols from the right (problem 8.2); evaluating works from the inside out, which is the same as running the machine left to right (8.3). Facts about δ̂ are proved by induction on |w| (8.8).
