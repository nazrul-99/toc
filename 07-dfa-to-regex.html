The R method (Kleene's construction)

Number the states q1, q2, …, qn. The expression Rᵏᵢⱼ describes every string that takes the DFA from qᵢ to qⱼ along a path whose intermediate states all have numbers ≤ k. The endpoints are not restricted. At k = n every path is allowed, so the language is the union of Rⁿ₁ⱼ over the final states qⱼ.

The two rules

Basis, k = 0 (no intermediate states): R⁰ᵢⱼ is the union of the symbols on arrows from qᵢ to qⱼ, ∅ if there are none, plus ε when i = j.

Induction: a path through states ≤ k either avoids qₖ in the middle, or visits it one or more times:

Rᵏᵢⱼ = Rᵏ⁻¹ᵢⱼ + Rᵏ⁻¹ᵢₖ ( Rᵏ⁻¹ₖₖ )* Rᵏ⁻¹ₖⱼ

The procedure

  1. Write the n² entries at level 0 straight from the arrows.
  2. For k = 1, 2, …, n compute every entry with the rule, and simplify immediately.
  3. You only need the entries that later entries use. The last level needs only Rⁿ₁ⱼ for final qⱼ.
  4. Answer: the union of Rⁿ₁ⱼ over the final states. Check it on a few strings (problem 7.4).

Every entry on these pages is checked automatically against the actual paths of the DFA, for all strings up to length 8.
