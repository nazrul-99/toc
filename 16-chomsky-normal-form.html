Conversion to Chomsky normal form

A grammar is in Chomsky normal form (CNF) if every production is A → BC (two variables) or A → a (one terminal). Every context-free language without ε has a CNF grammar. CNF parse trees are binary, which makes proofs and the CYK algorithm work.

The order taught in this course

  1. Remove ε-productions: find the nullable variables and rewrite each production with every nullable occurrence kept or left out (Section 14).
  2. Remove unit productions: find the unit pairs and copy non-unit productions along them (Section 15).
  3. Remove useless symbols: first non-generating, then unreachable (Section 13).
  4. Introduce terminal variables: in every right side of length ≥ 2, replace each terminal a by a new variable Tₐ with Tₐ → a.
  5. Break long right sides: replace A → B₁B₂…Bₖ (k ≥ 3) by A → B₁N₁, N₁ → B₂N₂, …, Nₖ₋₂ → Bₖ₋₁Bₖ.

Why this order? Step 1 can create unit productions (A → BC with B nullable gives A → C), step 2 can make symbols useless, and steps 4–5 need a clean grammar.

Naming the new variables

NameStands for
Ta, Tb, T0, …exactly one terminal: Ta → a
N1, N2, …the tail of a long right side; each Nᵢ derives exactly the symbols it replaces, and the same tail always reuses the same Nᵢ

About ε

CNF has no ε-productions, so if ε ∈ L the result generates L − {ε}. Some textbooks then add a new start symbol S₀ → S | ε; the pages note this whenever S is nullable.
