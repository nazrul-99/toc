The Chomsky hierarchy

A grammar is classified by the form of its productions α → β. Each type adds a restriction to the one above it, so the classes are nested. Capital letters are variables, small letters and digits are terminals, and S is the start symbol.

The four types

TypeNameEvery production must look likeMachine
3RegularA → a or A → aB (right-linear), or all of the form A → a or A → Ba (left-linear). S → ε is allowed. Left- and right-linear productions may not be mixed.Finite automaton
2Context-freeA → β: a single variable on the left, anything on the right.Pushdown automaton
1Context-sensitiveα → β with |α| ≤ |β| (non-contracting). S → ε is allowed only if S never appears on a right side.Linear bounded automaton
0Unrestrictedα → β with α non-empty. No other restriction.Turing machine

How to classify

  1. Check every production against the Type 3 rule. If all pass, and the grammar is consistently right-linear or left-linear, it is Type 3.
  2. Otherwise check whether every left side is a single variable: then it is Type 2.
  3. Otherwise check whether every production is non-contracting (|left| ≤ |right|): then it is Type 1.
  4. Otherwise it is Type 0.

Always answer with the most restrictive type. A regular grammar is also context-free, context-sensitive and unrestricted, but "Type 3" is the expected answer.

Grammar versus language

The type of a grammar depends only on its productions. The type of a language is the most restrictive type of any grammar generating it. Grammar 8 is Type 1, yet its language { abc, bac } is regular.
