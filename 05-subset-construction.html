Subset construction

A DFA can simulate an NFA by remembering the set of states the NFA could be in. Each such set becomes one DFA state. Since a set of n states has 2ⁿ subsets, the DFA is finite, though possibly much larger.

Definition

Given NFA N = (Q, Σ, δ, q₀, F), the DFA D has

start {q₀}    δ_D(S, a) = ⋃q∈S δ(q, a)    S final ⇔ S ∩ F ≠ ∅

For an ε-NFA, first remove the ε-arrows (Section 3), or equivalently start from ECLOSE(q₀) and close after every move.

The procedure (lazy construction)

  1. Start with the subset {q₀}. Put it on a work list.
  2. Take an unticked subset S. For each symbol a, compute T = ⋃q∈S δ(q, a), the union of the rows of the NFA table.
  3. New subset? If T is not yet in the DFA, add it to the DFA and to the work list. ∅ counts as a subset; it becomes the trap state.
  4. Tick S when both its cells are filled. Repeat until every subset is ticked.
  5. Mark final states: every subset that contains at least one NFA final state.
  6. Check: run a few strings through both machines. Each page here can verify the two agree on every string up to length 12.
