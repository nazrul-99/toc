Elimination of ε-productions

An ε-production has the form A → ε. For any context-free language L there is a grammar for L − {ε} with no ε-productions. The idea: instead of deriving ε from a variable later, decide right away to leave that variable out.

Nullable variables

A is nullable if A ⇒* ε. Compute them in rounds:

  1. Round 0: every A with a production A → ε.
  2. Next rounds: A is nullable if some production A → B₁B₂…Bₖ has only nullable variables on the right (no terminals).
  3. Stop when a round adds nothing.

Building the new productions

  1. For each production A → X₁X₂…Xₖ, let m be the number of nullable occurrences among the Xᵢ.
  2. Write all 2ᵐ versions obtained by keeping or leaving out each nullable occurrence. Each occurrence is decided separately, even if the same variable appears twice.
  3. Do not add a version whose right side is empty.
  4. Drop every A → ε.

The result generates L − {ε}. If the start symbol was nullable and ε must stay in the language, add a new start symbol S₀ → S | ε.
