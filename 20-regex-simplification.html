Algebraic laws for regular expressions

Two regular expressions are equivalent when they describe the same set of strings. The laws below are equivalences that hold for every choice of the languages L, M and N, so they can be used to rewrite and shorten expressions step by step, for example when simplifying the entries of the R method. Each example can be checked by testing strings.

Three traps

Concatenation is not commutative: 01 ≠ 10.   ∅* is ε, not ∅.   L + LL* is not L*: it misses ε (the correct law is ε + LL* = L*).

Quick check: true or false?

Decide whether each equation holds for all strings. A counterexample is shown when it does not.

Tools

Type an expression and let the laws of identity, annihilation, star and absorption simplify it.
