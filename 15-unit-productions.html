Elimination of unit productions

A unit production has a single variable on the right: A → B. It does no real work, it just renames. Unit productions can be removed without changing the language (after ε-productions have been removed).

Unit pairs

(A, B) is a unit pair if A ⇒* B using unit productions only.

  1. Basis: (A, A) is a unit pair for every variable A (zero steps).
  2. Induction: if (A, B) is a unit pair and B → C is a unit production, then (A, C) is a unit pair.
  3. Repeat until nothing new is added. Write down the reason for each pair: that is what the tabulation asks for.

The new grammar

For every unit pair (A, B) and every non-unit production B → α, add A → α. Then drop all unit productions.

Because (A, A) is a pair, every non-unit production of A is kept automatically.

Watch for cycles

If unit productions form a cycle (S → A → B → S), every variable on the cycle pairs with every other one. The method handles this naturally, but a "substitute once" shortcut does not.
