Designing Turing machines

A Turing machine M = (Q, Σ, Γ, δ, q₀, B, F) has a tape that is infinite in both directions, initially holding the input surrounded by blanks B, and a head that starts on the first input symbol. A move δ(q, X) = (p, Y, D) means: in state q reading X, write Y, move the head D ∈ {L, R}, and go to state p. In this section all machines are single-tape, single-head and deterministic.

Deciding and computing

TaskThe machine must
Decide a languagehalt on every input, in qa (accept) for strings in L and in qr (reject) otherwise
Compute a functionhalt in qf with the output written on the tape

Convention used on these pages: any (state, symbol) pair without a drawn arrow goes to qr. The transition tables show these entries in grey, so every transition is explicit.

Design techniques

TechniqueUsed in
Crossing off: replace matched symbols by markers (X, Y, Z) and repeat pass after pass1, 3, 6, 7, 9
Remembering in the state: carry a symbol across the tape in the state (q1 = "I saw a")4
Scanning like a DFA: move only right; the state stores what matters5, 10
Shape check first: verify the form a⁺b⁺ before counting6
Tape arithmetic: rewrite symbols in place (unary concatenation, binary carry)2, 8

Writing instantaneous descriptions

An ID writes the tape contents with the current state just before the scanned symbol, e.g. X a q1 b b means the head is on the first b in state q1. Each move gives the next ID with ⊢.
