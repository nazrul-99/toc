Thompson construction

The construction turns any regular expression into an ε-NFA by building a small machine for each symbol and joining machines in the order the operators apply. Every piece has exactly one start state and one final state, no arrow enters the start state from outside the piece, and no arrow leaves the final state. These rules let pieces be plugged together safely.

The four building blocks

R and S stand for pieces already built; here they are shown as single symbols.

The procedure

  1. Parse the expression. Star binds tightest, then concatenation, then union. Draw the parse tree if the expression is long.
  2. Build the leaves first. Each symbol occurrence gets its own two-state piece, even when the same symbol appears twice.
  3. Combine bottom-up. Concatenation: one ε-arrow from the final of R to the start of S. Union: new start, new final, four ε-arrows. Star: new start, new final, four ε-arrows (enter, repeat, leave, skip).
  4. Old finals stop being final whenever a piece is wrapped or joined. The finished machine has one final state.
  5. Check the count: states = 2 × (symbols + unions + stars) (problem 4.14).

Using the interactive pages

Each problem shows the parse tree next to the piece being built. The orange node is the subexpression of the current step, and green nodes are finished. In the diagram, new states are green and new arrows are orange. The finished machine can be tested with the simulator and verified against the expression. The last item in the menu lets you type any expression.
