Designing context-free grammars

A context-free grammar G = (V, T, P, S) has variables V, terminals T, productions P of the form A → α, and a start symbol S. Unless stated otherwise the alphabet is Σ = {a, b}.

The procedure

  1. Write down the shortest strings in L and a few that are not.
  2. Find what must match what (counts that are equal, symbols that mirror each other). Matched symbols are produced together by one production.
  3. Decide the base case from the smallest string (ε when n ≥ 0 is allowed, the shortest non-empty string when n ≥ 1).
  4. Use a separate variable for each independent block.
  5. Test: derive a few strings, and check that no unwanted string can be derived. Each page here checks every string up to a fixed length automatically.
