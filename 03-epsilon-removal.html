ε-transitions and their removal

An ε-NFA may change state without reading a symbol, along arrows labelled ε. Two tools handle these arrows: the ε-closure, and the removal construction that turns an ε-NFA into an ordinary NFA with the same states and the same language.

Definitions

ε-closure. ECLOSE(q) is the set of states reachable from q by following zero or more ε-arrows. It always contains q itself. For a set, ECLOSE(S) = ⋃q∈S ECLOSE(q) (problem 3.12).

Running an ε-NFA. Start in ECLOSE(q₀). For each input symbol a: move on a from every state in the set, then take the closure. Accept if the final set contains a final state.

Removal. Keep the same states. For every state q and symbol a set

δ′(q, a) = ECLOSE( δ( ECLOSE(q), a ) )

and make q final when ECLOSE(q) contains an old final state.

The procedure for removal

  1. Compute every closure first and keep them beside you.
  2. Close. For a cell δ′(q, a), start from X = ECLOSE(q).
  3. Move. Y = ⋃x∈X δ(x, a). Follow only arrows labelled a.
  4. Close again. δ′(q, a) = ECLOSE(Y). If Y = ∅ the cell is ∅.
  5. Repeat for every state and symbol. With n states and 2 symbols there are 2n cells.
  6. Choose the final states: q is final if ECLOSE(q) ∩ F ≠ ∅.
  7. Delete the ε-column. The result has the same number of states (problem 3.10).
